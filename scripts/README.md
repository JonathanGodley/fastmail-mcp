# Scripts

Developer tooling. None of it ships with the server; `dist/` is built from `src/` alone.

| Script | What it does |
| --- | --- |
| `mcp-harness.mjs` | Raw JSON-RPC client that spawns `dist/index.js` as a real MCP server. `createClient({ env })` → `init`/`call`/`close`, matching responses by JSON-RPC `id`. `node scripts/mcp-harness.mjs --list` dumps the advertised tool schemas. Use it rather than hand-writing a client. |
| `scan-secrets.mjs` | The PII/credential scanner the git hooks run (`npm run scan:secrets` for a full sweep). See `CONTRIBUTING.md`. |
| `vtimezone-scan.fuzz.mts` | An offline invariant sweep over the VTIMEZONE block scan behind #166 (`removeOrphanedVTimezones`, `regenerateVTimezones` in `src/caldav-client.ts`): needs no credentials, touches no network and does not use the built server. Run it with `npx tsx scripts/vtimezone-scan.fuzz.mts [iterations]` (default 200000). The invariant is described in its header and the mutations in its `MUTATE` list. Seeded, so a given count always generates the same payloads; exits non-zero on any violation or unexpected throw. Result on 25 Sep 2026, 200000 iterations: 337200 accepted, 62800 refused, 0 unexpected throws, 0 violations. |
| `comment-share.mjs` | `node scripts/comment-share.mjs <commit>` (or `--staged`, `--working`, `<a>..<b>`) says when a change added far more comment than the file it landed in carries - at least 20 comment lines at twice the file's own comment-per-code ratio. The pre-commit hook prints it; it never gates. Quiet unless something is over the bar; `--all` prints every measured file. |
| `find-raw-interpolations.mjs` | `node scripts/find-raw-interpolations.mjs [dir]` lists every `'${...}'` under `src/` rendered with no echo helper — the untrusted-values-in-prose class that the `echo-quoting convention` guard in `src/coerce.test.ts` provably **cannot** cover, because whether a value is untrusted depends on where it came from and nothing lexical separates the two. A hand-run inventory, not a test: the output is candidates to trace, never a defect list, and it always exits 0. |
| `mutation-test.mjs` | `npm run mutation -- <commit>` (or `--all`) runs Stryker mutation testing over the `src/` lines a commit changed, or all of `src/`, and prints Stryker's summary; survivors are untested lines. `--all --shard <i>/<n>` runs one size-balanced shard. Every mode writes a json report listing each mutant's status, errored ones included: `reports/mutation-commit.json` for a commit, `reports/mutation.json` for `--all`, and `reports/mutation-<i>-of-<n>.json` for a shard, which alone also writes an html report beside it. From a git worktree it uses the primary checkout's `node_modules`. See `CONTRIBUTING.md`. |
| `mutation-summary.mjs` | `node scripts/mutation-summary.mjs reports/mutation-*.json` prints Markdown totals, the score and the surviving mutants (capped at 200) from one or more shard reports. The weekly mutation workflow writes its output to the run summary. |
| `dump-official-surface.mjs` | Snapshots Fastmail's official MCP tool surface into `docs/official-mcp-*`, for comparing it with this server's tools. The output is deliberately not committed; the generator is. |
| `probes/` | On-demand live checks against a real account. See `probes/README.md` — they are not regression coverage, and some of them send mail. |
